Security

What the proxy layer actually enforces

SSRF protectionPrivate/loopback IP ranges blocked at the proxy layer
Scheme whitelistOnly http: and https: are ever proxied
Sandboxed iframeallow-scripts allow-forms allow-same-origin — no top navigation, no modals
No cookie forwardingThe proxy never sends Cookie or Authorization headers upstream
Referrer strippingAll requests use Referrer-Policy: no-referrer
Auto-abortStreams flagged malicious are aborted before any blob: URL is created

FAQ

Common questions

Does this need a paid VirusTotal key?

No — VT integration is entirely optional. Magic-byte and heuristic scanning both run without it.

Can I run this without deploying to Vercel?

Yes, GitHub Codespaces or plain npm run dev both work — Vercel is the fastest path, not the only one.

Why does the browser use an iframe instead of a real webview?

The sandboxed iframe with a strict CSP is what makes header-stripping and SSRF protection enforceable server-side — a true embedded webview would bypass the proxy layer entirely.
